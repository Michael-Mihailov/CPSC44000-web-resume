# CPSC44000 Web Resume

## Author

**Michael Mihailov**

## Project Description

This project is a web-based resume for CPSC44000 that presents my current resume using HTML and CSS.

The website displays my qualifications, technical skills, education, projects, research experience, and other professional information. A printable PDF version of the resume is also included and linked from the webpage.

The website is designed to provide a professional and responsive version of my resume while maintaining a format appropriate for Lewis University career services and internship applications.

This project was created for a Lewis University web development assignment and demonstrates the use of HTML, CSS, Bootstrap, responsive web design, browser printing, and Microsoft Azure.

## Running the Application

### Prerequisites

The application requires:

- A modern web browser
- Visual Studio Code or another text editor
- A local web server

### Running with Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Open `src/index.html`.
4. Right-click `index.html` and select **Open with Live Server**.
5. The resume will open in a web browser.

A local web server is recommended for testing the website and ensuring that all resources load correctly.

## PDF Version

A printable PDF version of the resume is included in the `src` folder.

The PDF is formatted for standard letter-size printing and can be accessed through the PDF link provided on the webpage.

## Deployment

The website is hosted using Microsoft Azure and is publicly accessible through an HTTPS URL.
